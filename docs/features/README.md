# Features

One folder per feature: `F-NNN-kebab-name/` containing:

- **`feature.md`** is the contract: what to build and how we know it is done. A human approves it before implementation.
- **`tasks.md`** is the execution plan: checkbox steps, grouped by layer.

Create one with `/feature-new <name>`, or copy [`_template/`](_template/).

## Status flow

`Draft` → `Approved` → `In progress` → `In review` → `Done`
